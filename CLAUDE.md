# puttr-app-2

Before building or changing any screen, component or style in this project, read [docs/design-guidelines.md](docs/design-guidelines.md) and follow it. It is the decided design system ("Broadcast", Matt, 2026-11-24): flat solid interface, 3D only inside bordered windows with text on a solid bar beneath, one lime main button per screen at most, one header on every tab, Montserrat in six sizes, radius 4, colours from its table only.

If a feature needs a component the guidelines do not have, add it to the guidelines first, then build it.
