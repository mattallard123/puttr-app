Improve and Profile, in 3D

Unity lets these two tabs stop being lists of cards. Each mockup keeps every piece of information the current screens carry (ImproveTab.cs, ProfileScreen.cs), shown once, and moves the Puttr world into the screen: the box and mat, the Player's stroke, the cup, the locker. Two directions for Improve, two for Profile, plus tablet landscape. Drag any 3D scene to orbit it, tap the stat cards to flip them.

Live 3DA real Unity scene (camera into a RenderTexture behind or inside the UI). Reuses game assets: Free putt box and mat, Lab stroke data, game backdrops.
UI FXUI Toolkit with a 2D trick for depth: Painter2D rings, scale-squash flips, shader sheen. UI Toolkit has no true 3D transforms on screen-space panels.
UIPlain UI Toolkit, App.uss tokens: dark ink, green 122,212,70, deep green 45,140,60, Montserrat.

How the live 3D gets into the UI

Each live region is a Unity camera rendering to a RenderTexture shown in a UI Toolkit element (Background image). One scene per tab, cameras moved between framings, not one scene per card. Stop rendering anything scrolled off screen; drop to 30 fps when idle.

Reuse, do not rebuild

  • Box, mat, hole, ball: the Free putt and Arcade scenes.
  • Stroke replay: Lab session putter path (LabSessionScreen data).
  • Columns and cups: AnalysisMath.Grid, the same 27 cells as Full analysis.
  • Coins, pennant, putter: League logos, putterBrands marks.

Rules kept

  • No number appears twice on one screen.
  • "Players", "Coaches", "Profiles" in copy.
  • Club gates unchanged: Full analysis, Compare, coach chat.
  • Kid profile: no coach chat, no custom games, Crew character instead of a photo.
